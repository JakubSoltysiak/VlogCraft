# Phase 3B picture scheduling and upstream references

The [previous comparison](STUDIO_3_6_0_PHASE3B_PLAYBACK.md#independent-completed-pictures-on-radeon-890m) recorded 35,702 source waits and 2,595 skipped frames on the experimental independent-device path. At that revision, the player started a transfer only after every source selector reported ready. Each selected picture change advanced the transfer generation. The source-wait count covered both source selection and copy availability, so the receipt cannot assign the waits to GPU completion or FFmpeg's device lock alone.

A producer-local fence would allow completion observation outside the immediate-context lock if measurements isolate that lock. |

The D3D11 contract orders `Signal` after preceding immediate-context work and exposes the current fence value on `ID3D11Fence`. A fence-based publication path would still need capability checks, a query fallback and the existing texture ownership transition. [Signal](https://learn.microsoft.com/en-us/windows/win32/api/d3d11_3/nf-d3d11_3-id3d11devicecontext4-signal) · [GetCompletedValue](https://learn.microsoft.com/en-us/windows/win32/api/d3d11_3/nf-d3d11_3-id3d11fence-getcompletedvalue).

The [previous OpenShot and mpv comparison](STUDIO_3_6_0_PHASE3B_PLAYBACK.md#ownership-and-measured-cost) still applies. OpenShot creates per-reader hardware devices and ordinarily downloads through a software transfer. mpv copies a decoder-array slice into renderable storage with D3D11 multithread protection. VlogCraft applies these design patterns in its own implementation and incorporates no upstream source code.

Run `python benchmarks/windows/completed_picture_probe.py <media> <new-output-directory> --scheduler` with the pinned Windows lab SDK and the existing NV12 and P010 fixtures. The probe advances the source clock while a transfer waits, holds another layer unavailable during successive prefetches and slot reuse, and requests the same source PTS across a true transport seek. Run the ordinary probe for GPU work in flight and consumer retirement. The existing [playback checks](STUDIO_3_6_0_PHASE3B_HANDOFF.md#independent-picture-handoff) cover the player entry point, including the outgoing tail and pixel parity.
