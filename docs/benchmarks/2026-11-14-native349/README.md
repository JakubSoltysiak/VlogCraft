# Studio 3.4.9 local reliability qualification

These records contain selected technical measurements and CameraA/B/C aliases. Private media, extracted pixels, source names/paths, GPS, device identifiers, raw project files and raw logs are excluded. The narrative report is [RELIABILITY_MEMORY_3_4_9.md](../../RELIABILITY_MEMORY_3_4_9.md).

The final visible comparison uses the packaged full-response clock transport, actual Windows DPI and `connect_over_cdp(no_defaults=True)`. Playwright 1.65.1 otherwise enables artificial page focus by default. Windows foreground, physical preview coverage, browser focus and device-pixel ratio are separate observations. The final ten trials per arm are collected in alternating frozen 3.4.8/current 3.4.9 pairs; the protected wall-time FPS is retained, including endpoint observation delay. The measurements are pending until the corresponding records are produced.

`initial-compact.json` retains the superseded ten-run variant, which subsequently failed long audio stress. `uncompressed-full-clock.json` retains the subsequent full-response package before checkpoint-history compression. `uncontrolled-current.json` retains all ten failed-consistency results of the compressed-history package, including the 1.3-second presentation gap. Those attempts and failed test fixtures remain in the history and report. They are not replaced by passing retries. `baseline348-archived.json` preserves the earlier verified ten-run reference; its emulated DPR and unrecorded foreground state differ from the final controlled protocol. It did not record its WebView runtime.

The protected workload uses original generated 4K60 H.264 sources, three video/three audio tracks, 1,500 clips and 125 seconds, with 960×540 composition and a 356×200 presentation surface. No proxies or intermediate encoded preview. Native source PTS, PCM sample budgets and Present/submission counters are different from physical scanout and acoustic synchronization. Histogram p95/p99 values are bucket upper bounds; exact per-frame variance was not retained.

Memory records separate summed RSS, private commit, live JS heap, DOM/listener counts and WebView process roles where available. RSS sums may count shared UMA pages twice. GPU-pool estimates are not added again to process totals. The analyzer uses actual sample times, 30-second medians, OLS with approximate Newey-West two-lag intervals, a warmed period and the late 15 minutes where available. One session is not a population-level reliability guarantee. GC is a post-stop diagnostic intervention only; the product does not force GC or reduce effective caches.

Export API controls and the historical direct-render worker experiment have different observation scopes. Keep both repeated timing distributions, codec/settings, full-decode/quality checks and measured conditions. A completion exit code alone does not establish performance equivalence, a stable memory plateau or production readiness. Hosted Actions validates correctness/build/install; hardware execution is local.
