# Editing capability matrix

“Tested” means the stated operation passed the specific checks in VERIFICATION.md. “Implemented” means the code is available with acceptance coverage outstanding. “Partial” identifies capabilities with specified gaps. “Missing” means there is no user-facing implementation.

| Capability | Status | Scope and gaps |
|---|---|---|
| Windows installer and desktop host | Tested | Per-user MSI, Start menu, WebView2 desktop window, bundled media tools. Single Windows 11 machine. Clean-VM qualification and code signing are outstanding. |
| Source linking and files beyond 4 GiB | Tested | Windows file-drop payload through the native WebView2 bridge, real allocated 4.64 GiB MOV, source frame beyond 4 GiB, proxy seek, edit, original-resolution export and separate sparse range/chunk checks. Physical Explorer gestures and a full multi-gigabyte browser upload remain untested. |
| Media formats and metadata | Partial | H.264 MP4, HEVC MOV and uncompressed MOV covered. MTS/M2TS, AVI, MKV, WebM, AV1 decode, long-GOP camera clips, VFR timestamps, rotated media, 6K and 8K need an acceptance corpus. Import uses an extension allowlist. |
| Background jobs | Partial | Probes run on request threads, thumbnails and peak waveforms use a worker pool, proxies run serially with progress. Desktop import cancellation stops subsequent work at file boundaries. Current-file probe interruption, resumable cache jobs, cache eviction and lifecycle benchmarks remain. |
| Project management | Tested | Linked project files, atomic replacement, durable backup, previous-revision recovery, preserving invalid files and relinking. The disk-full test injects a filesystem failure. Schema-2 migration and cross-machine portable media archives need further work. |
| Multitrack timeline | Partial | Add video/audio tracks without a numerical track ceiling. Name, color, order, height, mute, solo, hide, lock and gain. Trim, move, split, duplicate, delete, track-local ripple delete, snapping, undo/redo and source in/out. One selected clip at a time. |
| Timebase and timeline performance | Partial | Integer sequence-frame partitioning for render segments and frame-stepped playhead. Source in/out are seconds in the compatible project format. Viewport culling and indexed active-clip lookup. No complete rational source timebase, fractional NTSC sequence rates, frame-locked interactive playback or EDL interchange. |
| Advanced editing | Missing | Rolling, slip/slide, insert/overwrite modes, explicit A/V links, groups, multiselection, clip clipboard, nested sequences, sequence markers and editable shortcut sets. |
| Compositing and transitions | Partial | Video layers, PIP, fit/fill, scale, opacity, position, titles, image overlays and fades. Overlapping fades can form a dissolve. Blend modes, adjustment layers, masks, feathering, wipes, chroma key, reverse, freeze, speed ramps, grain and a plugin interface remain. |
| Animation | Partial | Source-time X/Y and gain curves, hold, linear, ease-in/out and editable cubic Bézier handles with curve copy/paste. FFmpeg approximates Bézier in 64 intervals per segment. Rotation, anchor, scale, animated opacity, crops, masks and general effect automation remain. Still/title split remapping and long dense curves need further qualification. |
| Point tracking | Partial | Forward/backward optical-flow consistency check for a selected detail, attach translation to an overlapping layer, apply results as editable position keys. Synthetic known-displacement check. No rotation, perspective, planar masks, occlusion recovery or per-frame corrective retracking. |
| Stabilization | Tested | Global translation estimation, adjustable smoothing, zoom compensation and native-resolution export. Decoded test output reduced inter-frame jitter on synthetic footage. Qualification on handheld wildlife footage and rotational, rolling-shutter and horizon correction remain. |
| Color grading | Partial | Six SDR looks and a decoded monochrome test. Live CSS looks approximate FFmpeg grading. Wheels, curves, numeric primary correction, LUT import, wipe comparison and calibrated scopes remain. |
| HDR | Partial | FFprobe flags PQ/HLG; original renderer attempts SDR tone mapping. Full metadata handling, reference monitoring, proxy/preview parity, HDR10/HLG output and color accuracy are unqualified. Delivery targets SDR. |
| Audio | Partial | Original camera audio, independent tracks, mixed AAC delivery, clip/track gain, per-clip gain keys, mute/solo, fades and cached peak overviews. Monitor element volume clamps at unity. Pan, peak meters, normalization, EQ, compressor, noise reduction, speech ducking, WAV delivery and sample-locked monitoring remain. |
| AI editing | Partial | Offline review MP4/ZIP. Strict track-addressed property edits, approval digest, locked-track checks and undo. Existing optional online analysis still uses the main-track rough-cut format. Live API calls, speech/music analysis and invoking motion jobs from a proposal are untested or missing. |
| Export and acceleration | Partial | Original-media rendering, 24/25/30/50/60 fps, custom dimensions, bitrate or CPU quality, H.264/HEVC/AV1, AMD AMF tested. QSV/NVENC exposed on passing runtime probe. Compositing remains CPU-based. Full hardware decode, ProRes/DNxHR, batch/range export, saved presets and estimated file size remain. |
| Workspaces and ergonomics | Partial | Integrated media library, source/program monitor, inspector, motion dialog, export and AI dialogs, resizable timeline, keyboard actions and tested narrow layout. Separate dockable color/audio/effects workspaces and accessibility qualification remain. |
| Reliability and performance | Partial | Local diagnostic log, atomic project publication and export replacement. Synthetic 104-track/1,500-clip state validated. No full-length mixed-media stress render, sustained 4K60 playback measurement, GPU occupancy study, recovery journal or diagnostic bundle. |
| Professional interchange and finishing | Missing | AAF/OTIO/XML interchange, multicam, color-managed external monitoring, collaborative editing and mastering workflows. |

## Continuation in dependency order

1. Add versioned rational sequence rates and integer source ticks. Migrate v3, preserve old projects, and test 24000/1001, 30000/1001, VFR PTS, speed changes and repeated one-frame cuts against decoded frame identifiers.
2. Prototype an MLT producer/tractor/consumer against the same project model and an FFmpeg reference export. Measure seek latency and A/V drift over one hour. Pick the interactive backend after decoding and color results agree on the Windows fixture set.
3. Introduce timeline commands with inverses and persistent transactions. Build rolling/slip/slide, linked selections, ripple across tracks, insert/overwrite, markers and nesting on those primitives. Add crash injection through actual process death and test concurrent opens.
4. Extend the shared parameter evaluator to scale, rotation, opacity, audio pan and masks. Add rendered frame comparison tests, calibrated SDR grading, scopes and LUTs. Then qualify managed HDR using reference charts and verified metadata. Extend tracking to rotation and corrective anchors.
5. Implement a shared audio engine with sample-accurate automation, gain above unity, meters, EQ and ducking. Carry speaker/music measurements into offline AI proposals. Extend the optional cloud path to the same multitrack manifest with per-request material selection.
6. Build portable projects, configurable caches, durable cancellable background analysis, range/batch exports and professional intermediates. Verify installation/upgrade on clean Windows images, test other GPU vendors, and run long projects with real camera footage before promoting the build.
